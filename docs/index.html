What it does

Built by a KFUPM student for KFUPM students.

The official catalog

2,123 undergraduate courses from 58 departments, taken from bulletin.kfupm.edu.sa. One button refreshes it every term.

Checkboxes, not typing

Filter by department, search by code or title, tick your courses. The matching keywords are generated for you.

Smart matching

COE 301 catches COE301_Lab.pdf, coe-301 HW.docx and 261-COE301-L1.pdf, but never COE 3011.

Your own filters

Internship, a club, a side project: add a folder and a few keywords, like "Internship" with "internship, coop".

Everything else, by type

Files that match no course go to Documents, Images, Videos, Installers, Archives and more.

Safe by design

It never deletes and never overwrites. Unfinished downloads are left alone. Nothing leaves your device.

Get it

Two minutes to set up. Then you can forget about it.

Windows

  1. Download KFUPM-Sorter-Setup.exe and run it. No administrator rights are needed.
  2. Tick your courses and add any custom filters.
  3. Press Save and turn on automatic sorting. It checks your Downloads quietly every minute and starts with Windows.
Download for Windows
"Windows protected your PC"? The installer is not code-signed yet, so Windows shows this for any new app. Click More info, then Run anyway. Every line of code is public on GitHub.

iPhone & iPad

  1. Open this page on your iPhone or iPad and tap Get the Shortcut, then Add Shortcut.
  2. Run it once from the Shortcuts app, choose your Downloads folder, then Pick my courses.
  3. Add an automation: When Safari is closed → run KFUPM Sorter. The guide shows how.
Get the Shortcut Step-by-step guide
Apple devices use Apple's own Shortcuts app, so there is nothing to install from outside the App Store. Shortcuts sync over iCloud to your iPad and Mac.

Mac

  1. Download the file for your Mac, open it and drag KFUPM Sorter Desktop into Applications.
  2. The first time, right-click the app and choose Open. When asked, allow access to Downloads.
  3. Tick your courses, press Save and turn on automatic sorting. It runs from the menu bar.
Download for Mac (M1 or newer) Mac with Intel
The Mac app is a separate project, KFUPM Sorter for Windows and Mac, written in Java with Java built in. It is not notarized by Apple yet, which is why the first start needs a right-click. The same app also runs on Windows: KFUPM-Sorter-Windows-Setup.exe.
